# Security

Please do not open a public issue for security vulnerabilities.

Reporting process, scope, and disclosure expectations are defined in
[`docs/27-repository-and-contributing.md`](docs/27-repository-and-contributing.md)
(see "Issue templates" — security vulnerabilities require a private
reporting route) and
[`docs/20-privacy-and-security.md`](docs/20-privacy-and-security.md).

A dedicated private contact address has not yet been finalized (tracked as
a release-blocking open question in
[`docs/48-open-questions-and-decisions.md`](docs/48-open-questions-and-decisions.md)).
Until then, coordinate through the repository's private security advisory
feature if hosted on a platform that supports one.
