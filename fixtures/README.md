# Fixtures

Reserved for repository-wide test fixtures (sample library layouts,
synthetic media metadata) that don't belong to a single crate. See
[`docs/46-implementation-plan.md`](../docs/46-implementation-plan.md).

Connector contract-test fixtures (booru API responses, OPDS catalog feeds,
RSS/Atom samples) live alongside the connector code instead, at
[`crates/connectors/fixtures/`](../crates/connectors/fixtures/).
