# Software Bill of Materials

One [CycloneDX](https://cyclonedx.org/) 1.3 JSON SBOM per workspace crate, generated by [`cargo-cyclonedx`](https://github.com/CycloneDX/cyclonedx-rust-cargo) — the "dependency inventory"/"SBOM" deliverable from `docs/46-implementation-plan.md`'s Workstream 13.

These are machine-generated, not hand-maintained. Regenerate after any dependency change:

```bash
cargo install cargo-cyclonedx --locked   # once
cargo cyclonedx --format json
mv crates/*/*.cdx.json sbom/
```

For dependency-vulnerability/license scanning, see `deny.toml` (`cargo deny check`) instead — these SBOM files are an inventory snapshot, not a live scan.
