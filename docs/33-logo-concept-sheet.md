# Veloura Logo Concept Sheet

> This is a later, refined revision of [31 — Veloura Logo Concept Sheet](31-logo-concept-sheet.md): it adds a construction grid, concrete hex colorways, and a recommended concept, but drops 31's Concept D ("Veiled Bookmark"). Treat this document as the current direction for Concepts A–C; consult 31 if the Veiled Bookmark concept is needed.

## Brand name

**Veloura**

Primary shorthand:

```text
V/
```

## Concept A: Offset Cards

Two offset rounded rectangles form an abstract `S`.

- Upper card contains a play-triangle cutout.
- Lower card contains an index-tab cutout.
- Negative space creates the letter.
- Best for the application icon and splash screen.
- Full-colour treatment uses the indigo–iris–lavender gradient.
- One-colour treatment uses off-white on pure black.

## Concept B: Index Slash

A geometric `S` paired with a forward slash:

```text
V/
```

The slash represents:

- A file path
- CLI syntax
- Forward movement
- A page divider
- An indexed source route

Best for:

- TUI header
- CLI help
- Favicon
- Compact navigation rail

## Concept C: Aperture Index

A circular mark combines:

- A media aperture
- Four index tabs
- A central S-shaped negative space

Best for:

- Larger marketing artwork
- Loading animation
- Plugin registry identity

It is less suitable than Concept A for very small sizes.

## Recommended direction

Use **Concept A** as the primary icon and **Concept B** as the compact companion mark.

## Colour variants

### Full colour

```text
#6366F1 → #8B5CF6 → #C4B5FD
```

Optional ocean accent:

```text
#7BC4C4 → #6EE7B7 → #7FFFD4
```

### Monochrome dark

- Mark: `#F2F0EA`
- Background: `#000000`

### Monochrome light

- Mark: `#11151D`
- Background: `#F3F1EC`

### Warning or development build

A small yellow `#FFD166` corner tab may distinguish beta or developer builds. Do not recolour the entire logo red or yellow.

## Geometry

Recommended construction grid:

```text
24 × 24 units
```

- Outer safe area: 2 units
- Card corner radius: 3 units
- Internal gap: 2 units
- Slash angle: approximately 18 degrees
- Minimum cutout width: 2 units

## Clear space

Minimum clear space equals the width of the slash stroke on all sides.

## Minimum sizes

- App icon: 32 px
- Compact mark: 16 px
- Wordmark: 96 px wide
- TUI mark: 2 characters

## Wordmark

Use a modern humanist sans-serif.

Recommended arrangement:

```text
VELOURA
INDEX
```

or:

```text
Veloura
```

The stacked version works for launch screens. The horizontal version works for navigation and documentation.

## Do

- Keep the mark simple.
- Preserve negative space.
- Use pure black or transparent backgrounds.
- Use one gradient at a time.
- Provide a monochrome variant.
- Align the wordmark optically rather than mathematically.

## Do not

- Add explicit imagery.
- Use a glossy 3D treatment.
- Add more than one symbol to the core mark.
- Use red for the standard brand mark.
- Place the gradient over detailed media.
- Distort the slash angle.
