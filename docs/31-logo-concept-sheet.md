# Veloura Logo Concept Sheet

> This is the original concept sheet, with four concepts (A–D). [33 — Veloura Logo Concept Sheet](33-logo-concept-sheet.md) is a later, more refined direction (construction grid, hex colorways, a recommended concept) but drops Concept D ("Veiled Bookmark") — it does not fully supersede this document.

## Concept A — Offset Cards S

Two overlapping media cards create an `S` in negative space.

- Upper card: play-triangle cutout
- Lower card: index-tab cutout
- Best for: app icon and product mark
- Accent: indigo → iris → lavender
- Neutral version: off-white on pure black

## Concept B — S Slash

A compact monogram:

```text
V/
```

The slash suggests:

- CLI paths
- search syntax
- forward navigation
- an index marker

Best for the TUI header, favicon, tray icon, and developer branding.

## Concept C — Aperture Index

A circular aperture interrupted by two horizontal index tabs.

- Suggests viewing, media, and cataloguing
- More technical and less literary
- Best for player controls and a compact app icon

## Concept D — Veiled Bookmark

A bookmark silhouette split by a curved diagonal veil.

- Suggests privacy and saved collections
- Softer and more editorial
- Best for marketing and reader-oriented surfaces

## Lockups

- Horizontal: mark + `Veloura`
- Compact: mark + `Veloura`
- Icon only
- Neutral launcher version
- TUI wordmark: `VELOURA`
- CLI signature: `veloura /`

## Clear space

Use one-half of the mark width on all sides.

## Minimum size

- App icon: 24 px
- UI mark: 16 px
- Horizontal lockup: 96 px wide
- TUI text mark: no graphic below 16 terminal columns

## Colorways

1. Indigo / iris / lavender on black
2. Moonstone / mint / aquamarine on black
3. Off-white on black
4. Black on off-white
5. Red reserved for safety or error contexts, not the default logo
6. Yellow reserved for warnings or limited-edition highlights
