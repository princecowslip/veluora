# Feature Catalogue

## Library features

| Feature | MVP | Later | Notes |
|---|---:|---:|---|
| Folder indexing | Yes |  | Non-destructive by default |
| Managed library |  | Yes | Optional file organization |
| Hash matching | Yes |  | Preserve state across moves |
| Perceptual duplicate grouping |  | Yes | Reviewable, never auto-delete |
| Metadata editing | Yes |  | Local overrides preserved |
| Metadata providers |  | Yes | Separate from media connectors |
| Import/export | Yes |  | Versioned JSON and optional CSV |
| Filesystem watch | Yes |  | Debounced and recoverable |
